# EazyLedger

EazyLedger 是一款面向 Windows 的本地资料台账管理工具。它把分散在不同文件夹中的资料导入独立资料库，以树状节点、彩色标签、全文搜索、有效期和预览能力组织文件，同时保留桌面文件管理器熟悉的操作方式。

当前版本：**v0.4.9**

## 产品定位

EazyLedger 适合管理合同、证书、产品资料、投标文件、人员资质、制度文件和其他需要长期归档、分类检索或关注有效期的资料。

- 数据默认保存在本机，不依赖在线账户。
- 台账节点负责确定资料的主要归档位置。
- 标签负责跨节点的多维分类。
- 搜索同时覆盖名称、标签、备注和可提取正文。
- 导入后的资料由 EazyLedger 保存为独立副本，不与原始来源文件自动同步。

## 核心功能

### 台账架构

- 创建任意层级的树状台账节点。
- 通过右键菜单新建子节点、重命名、升级、降级、复制或删除节点。
- 拖动节点到另一节点的上方、中央或下方，分别执行同级前插、设为子节点或同级后插。
- 自动阻止节点移动到自身或自己的下级节点。
- 记忆同级节点顺序，重启应用后保持不变。
- 主页完整展示台账树，并支持逐级、全部或指定深度展开。
- 左侧“台账架构”区域可以独立折叠并记忆状态。

### 文件导入与管理

- 导入单个或多个文件。
- 导入整个文件夹，并自动保留原文件夹层级。
- 将系统外部文件或文件夹直接拖入应用。
- 拖动单个文件或当前多选文件到左侧节点，快速调整台账归属。
- 支持单选、多选、范围选择和全选。
- 支持复制、剪切、粘贴、重命名和创建副本。
- 删除文件或节点时先移入应用回收站。
- 双击文件时使用 Windows 默认程序打开。
- 可以从属性面板在资源管理器中定位台账副本。
- 文件列表支持按名称、修改时间、类型、大小和有效期排序，并记忆排序偏好。
- 文件右键菜单提供主要管理操作，文件行不再重复显示三点菜单。
- 自动忽略 `Thumbs.db`、`desktop.ini`、`.DS_Store`、Office 临时锁文件等系统杂项；文件夹导入时也会跳过系统回收站、卷信息和 `__MACOSX` 目录。
- 已经登记在旧资料库中的系统杂项会从列表、搜索、节点计数和标签计数中隐藏，但不会自动删除磁盘文件。

### 标签与检索

- 创建、重命名、改色或删除标签。
- 提供 20 种预设颜色，并支持任意自定义颜色。
- 一个文件可以同时拥有多个标签。
- 标签以彩色胶囊显示在文件名旁。
- 左侧“标签”区域可以独立折叠并记忆状态。
- 支持按单个标签浏览资料。
- 支持关键字与多个标签组合筛选。
- 多标签筛选采用 AND 逻辑。
- 搜索范围包括文件名、标签、备注以及 DOCX/TXT 等可提取正文。

### 有效期与通知

- 为任意文件设置、修改或清除有效期。
- 根据剩余时间显示不同颜色的状态标记。
- 已过期和临期资料在文件列表中获得醒目标识。
- 主页集中展示已过期及 30 天内到期的资料。
- 通知中心从右侧滑出，不会因点击铃铛重复生成通知。
- 通知历史保存告警时间、已读状态和对应文件。
- 支持单条查看和全部标记已读。
- 最多保留最近 200 条通知记录。

### 文件预览

- 图片支持内置预览、旋转、缩放、复位和全屏。
- PDF 支持内置预览、旋转、缩放、复位和全屏。
- DOCX 使用分页 Word 渲染器，展示段落、图片、表格、页眉和页脚等常见结构。
- 旧版 DOC 会在本机存在 LibreOffice 时转换成缓存 PDF 预览。
- DOC 转换只生成预览缓存，不会修改原始文档或台账副本。
- LibreOffice 不可用时会显示明确说明，并提供“使用默认程序打开”。
- TXT、Markdown、CSV、JSON、XML 和日志文件支持文本预览。
- 单选文件后可在右侧编辑标签、备注和有效期。
- 预览面板可以随时隐藏或显示。

### 资料库与安全

- 导入默认采用复制方式，原始来源文件保留不变。
- 每个导入文件使用独立 ID 和独立存储目录，因此允许同一节点存在多个同名文件。
- 在 EazyLedger 中移动文件只改变台账节点归属，不改变原始来源文件。
- 在 EazyLedger 中重命名、编辑或删除只影响资料库副本，不影响原始来源文件。
- 资料库位置可以在设置中迁移。
- 设置页可以直接打开当前资料库文件夹。
- 支持创建完整资料库备份。
- 支持导出 JSON 台账清单。
- 应用更新不会覆盖资料库和数据库。

### 桌面交互

- 使用适合 Windows 的 Fluent 风格界面：顶部导航和紧凑列表延续 Files 的桌面层级，主页、属性与对话框采用 Papra 式克制文档表面。
- 使用多标签页在主页、节点和设置之间切换。
- 支持外部文件拖入与内部 Pointer Events 拖拽同时工作。
- 新建、重命名、移动和删除均使用 EazyLedger 自有对话框。
- 危险操作使用统一警示确认框。
- 普通错误与结果使用应用内轻提示，不再显示带有“tauri.localhost”的浏览器原生弹窗。
- 支持通知侧栏、标签气泡菜单、有效期菜单和文件右键菜单。
- 更新页区分连接中、GitHub 响应较慢、已连接且无新版、下载校验以及具体失败原因。
- 更新失败可识别超时、网络不可达、GitHub 限流、Release 清单异常和签名失败，并保留可展开的技术信息。

## 快速开始

1. 启动 EazyLedger。
2. 创建适合业务的台账节点，例如“产品资料”“人员证书”或“合同”。
3. 使用“导入资料”“导入文件夹”或直接拖入文件。
4. 为资料添加标签、备注和有效期。
5. 使用左侧台账树、标签或顶部搜索框查找资料。
6. 需要编辑内容时，从 EazyLedger 双击打开文件。
7. 需要整理、复制、重命名或删除时，优先在 EazyLedger 界面内操作。

## 文件与原始来源的关系

EazyLedger 采用“导入副本”模式，而不是持续引用原始文件。

| 操作 | 台账资料库副本 | 原始来源文件 |
|---|---|---|
| 导入文件 | 创建独立副本和数据库记录 | 保留不变 |
| 修改原始文件 | 不自动同步 | 被修改 |
| 从台账打开并保存 | 更新资料库副本及索引 | 不受影响 |
| 移动到其他节点 | 只改变台账分类 | 不受影响 |
| 重命名或添加标签 | 更新副本名称或数据库信息 | 不受影响 |
| 从台账删除 | 副本移入应用回收站 | 不受影响 |
| 删除原始文件 | 台账副本仍可使用 | 原文件被删除 |

不要在资源管理器中手动移动、删除或重命名资料库内部文件，否则数据库记录可能失去对应文件。内容编辑可以从 EazyLedger 打开后在 Word、图片编辑器或其他默认程序中完成。

## 预览格式

| 格式 | 内置预览 | 说明 |
|---|---|---|
| PNG、JPG、JPEG、GIF、WebP、BMP | 支持 | 支持旋转、缩放和全屏 |
| PDF | 支持 | 使用内置 PDF 查看器 |
| DOCX | 支持 | 使用浏览器端分页渲染，复杂版式可能与 Word 略有差异 |
| DOC | 条件支持 | 需要系统安装 LibreOffice，转换结果仅作为缓存 |
| TXT、MD、CSV、JSON、XML、LOG | 支持 | 以可滚动文本方式显示 |
| 其他格式 | 外部打开 | 使用 Windows 默认程序 |

## 常用快捷键

| 快捷键 | 功能 |
|---|---|
| Ctrl+A | 全选当前列表 |
| Ctrl+C | 复制所选文件 |
| Ctrl+X | 剪切所选文件 |
| Ctrl+V | 粘贴到当前节点 |
| F2 | 重命名单个所选文件 |
| Delete | 将所选文件移入应用回收站 |
| Esc | 清除选择、关闭菜单或退出全屏预览 |

## 设置

设置页集中管理以下内容：

- 当前资料库位置。
- 打开资料库文件夹。
- 创建完整备份。
- 迁移到新的资料库位置。
- 切换到空资料库。
- 默认是否显示预览面板。
- 当前应用版本和软件更新。

资料库迁移要求选择空目录，并在重启后生效。旧资料库不会自动删除。

## 开发运行

开发环境需要 Node.js、Rust、Microsoft C++ Build Tools 和 WebView2。

    npm install
    npm run build
    npm run tauri dev

浏览器运行 npm run dev 时使用内置示例数据，只用于界面开发；桌面模式才会操作真实本地资料库。

## 当前边界

- DOCX 预览覆盖常见内容和版式，但不保证与 Microsoft Word 像素级一致。
- DOC 预览依赖 LibreOffice；未安装时只能外部打开。
- PDF 暂未提取正文用于全文搜索。
- 台账清单目前导出为 JSON，尚未提供 Excel/CSV。
- 应用回收站暂未提供图形化恢复界面。
- 节点同级顺序和部分界面偏好保存在本机应用设置中。
