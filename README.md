# EazyLedger

EazyLedger 是一款面向 Windows 的本地资料台账管理工具。它把分散在不同文件夹中的资料导入独立资料库，以树状节点、彩色标签、全文搜索、有效期和预览能力组织文件，同时保留桌面文件管理器熟悉的操作方式。
本项目通过 ChatGPT 与 GitHub 连接器协作开发，并使用 GitHub Actions 构建和发布 Windows 安装包。

当前版本：**v0.5.3**

## 产品定位

EazyLedger 适合管理合同、证书、产品资料、投标文件、人员资质、制度文件和其他需要长期归档、分类检索或关注有效期的资料。

- 数据默认保存在本机，不依赖在线账户。
- 台账节点负责确定资料的主要归档位置。
- 标签负责跨节点的多维分类。
- 搜索同时覆盖名称、标签、备注和可提取正文。
- 导入后的资料由 EazyLedger 保存为独立副本，不与原始来源文件自动同步。

## 核心功能

### 1、台账架构

- 用树状节点还原业务目录，支持新建、重命名、复制、移动和删除节点。
- 节点可通过拖拽调整同级顺序、层级和归属位置。
- 主页提供完整架构图，可全部展开、全部收起或按指定深度浏览。

### 2、文件导入与管理

- 支持选择文件、导入文件夹、拖放以及从 Windows 资源管理器复制后按 Ctrl+V 导入。\n- 支持把台账资料拖出到资源管理器或桌面，也可在应用内复制后到外部按 Ctrl+V 粘贴。
- 默认把文件复制进独立资料库，保留原始来源文件。
- 支持应用内复制、剪切、粘贴、移动、重命名、星标置顶和多种排序。
- 自动过滤 Thumbs.db、desktop.ini、Office 临时文件等系统杂项。
- 删除方式可选应用回收站、Windows 系统回收站或直接永久删除。

### 3、标签与检索

- 为同一份资料添加多个彩色标签，跨台账节点建立多维分类。
- 标签显示在文件副标题区域，不挤占文件名；显示数量可设为 1–10 个，超出部分折叠为“+N”。
- 搜索覆盖文件名、标签、备注和可提取的正文，并支持多个标签的“且”组合筛选。

### 4、有效期与通知

- 为文件设置有效期，在列表和预览区显示状态。
- 主页集中展示已过期和 30 天内即将到期的资料。
- 通知中心保留告警历史并支持已读状态。

### 5、文件预览

- 内置图片、PDF、DOCX 和常见文本格式预览。
- 图片与 PDF 使用统一的旋转、缩放和全屏控制；Ctrl+滚轮与工具栏共享同一缩放状态。
- 旧版 DOC 可借助本机 LibreOffice 转换为缓存 PDF 后预览。

### 6、资料库与安全

- 数据库、导入副本和缓存默认保存在本地，可迁移资料库并创建完整备份。
- 应用回收站提供查看、恢复、清空和打开目录功能，默认位于资料库的 `database/trash`。
- 应用回收站路径可单独调整，迁移时会保留现有回收站内容。
- 软件更新从 GitHub Release 获取签名安装包，并显示检查、连接、下载和失败诊断状态。

### 7、桌面交互

- 提供标签页、面包屑、右键菜单、键盘快捷键和 Windows 资源管理器式选择逻辑。
- 常用快捷键包括 Ctrl+A、Ctrl+C、Ctrl+X、Ctrl+V、F2 和 Delete。
- 新建、移动、重命名、删除等操作统一使用应用内对话框。

## 快速开始

1. 启动 EazyLedger。
2. 创建适合业务的台账节点，例如“产品资料”“人员证书”或“合同”。
3. 使用“导入资料”“导入文件夹”或直接拖入文件。
4. 为资料添加标签、备注和有效期；将常用资料设为星标即可固定在列表顶部。
5. 使用左侧台账树、标签或顶部搜索框查找资料。
6. 需要编辑内容时，从 EazyLedger 双击打开文件。
7. 需要整理、复制、重命名或删除时，优先在 EazyLedger 界面内操作。

## 预览格式

| 格式 | 内置预览 | 说明 |
|---|---|---|
| PNG、JPG、JPEG、GIF、WebP、BMP | 支持 | 支持旋转、缩放和全屏 |
| PDF | 支持 | 使用内置 PDF 查看器 |
| DOCX | 支持 | 使用浏览器端分页渲染，复杂版式可能与 Word 略有差异 |
| DOC | 条件支持 | 需要系统安装 LibreOffice，转换结果仅作为缓存 |
| TXT、MD、CSV、JSON、XML、LOG | 支持 | 以可滚动文本方式显示 |
| 其他格式 | 外部打开 | 使用 Windows 默认程序 |

## 开发运行

开发环境需要 Node.js、Rust、Microsoft C++ Build Tools 和 WebView2。

    npm install
    npm run build
    npm run tauri dev

浏览器运行 npm run dev 时使用内置示例数据，只用于界面开发；桌面模式才会操作真实本地资料库。

## 当前边界

- DOCX 预览覆盖常见内容和版式，但不保证与 Microsoft Word 像素级一致。
- DOC 预览依赖 LibreOffice；未安装时只能外部打开。
- PDF 暂未提取正文用于全文搜索。
- 台账清单目前导出为 JSON，尚未提供 Excel/CSV。
- 节点同级顺序和部分界面偏好保存在本机应用设置中。

## 版本历史

### v0.5.3

- 接通双向 Windows 文件剪贴板：台账资料复制后可粘贴到资源管理器或桌面，资源管理器中的文件复制后也可直接粘贴导入当前节点。
- 修复中文路径经过 PowerShell 标准输出时受 Windows 本地代码页影响、被误判为空剪贴板的问题。
- 粘贴时优先识别 Windows 文件剪贴板，没有外部文件时再执行应用内复制或剪切，避免旧的内部剪贴板遮蔽外部复制内容。
- 文件拖出应用窗口边界时切换为 Windows 原生文件拖动；窗口内拖到台账节点仍沿用现有移动逻辑。

### v0.5.2

- 修复应用回收站打开时，清空确认框被回收站抽屉遮挡的问题；所有应用内对话框现在统一显示在侧栏和遮罩之上。
- 修复软件更新错误信息被压进窄列后逐字竖排的问题，恢复状态图标、标题、可换行说明和受限高度的技术信息区域。
